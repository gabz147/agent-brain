# Templates

- [[Manual Daily Note Template]]: human-authored daily-note output, expanded by Obsidian's Daily Notes command. `(human)`
- [[Job Template]]: one note per recurring task, with its read-first links, procedure, quality bar and lessons. `(human)`

The agent template is [[Daily Note Template]] under Daily Notes. The two templates have different attribution: agents use their actual runtime model; manual creation signs human. See [[Vault Workflow Contract]].
